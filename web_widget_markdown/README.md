# Markdown格式widget模块
=================================
## Odoo 18.0 (社区版)

全局通用模块：
=================================
1、安装此模块；
2、xml里面的Html和Text类型字段添加上：widget="bootstrap_markdown"
3、完整代码：<field name="ai_response" widget="bootstrap_markdown"/>
