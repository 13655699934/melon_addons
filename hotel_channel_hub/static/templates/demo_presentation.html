✨ 核心功能特性

多酒店管理

支持集团化酒店管理，统一平台管理多家酒店，包含酒店信息、房型配置、房间状态等

房态管理

实时房态监控，支持空闲、已预订、已入住、维修中等多种状态，可视化看板展示

订单流程

完整的订单生命周期管理，从草稿到确认、入住、退房，支持取消和一键复刻

渠道聚合

对接携程、去哪儿、美团等OTA平台，统一管理线上线下订单，实时库存同步

API接口

提供完整的RESTful API，支持第三方系统对接，Token认证保证安全性

数据分析

实时统计入住率、收入、订单趋势等关键指标，支持多维度数据分析

💻 API接口

完整的RESTful API，支持第三方系统对接

API端点列表

获取Token

GET /api/channel/token
根据企业标识获取或生成API Token

获取房间列表

GET /api/hotel/rooms
查询酒店、房型、房间静态信息

创建订单

POST /api/order/create
创建订单，自动扣减库存

更新订单

POST /api/order/update
更新订单信息、取消订单

查询订单

GET /api/order/detail
根据订单号查询订单详情

更新价格库存

POST /api/room/update
批量更新房间价格和可售库存

认证方式

认证类型：
Bearer Token
Header：
Authorization: Bearer YOUR_TOKEN
Token有效期：
365天
安全性：
支持Token轮换，自动记录API调用日志

响应格式

{
    "code": 0,
    "msg": "success",
    "data": {
        "order_id": 123,
        "order_no": "HO202511090001",
        "status": "confirmed"
    }
}
