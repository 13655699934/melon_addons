mln · Drag Drop Image Gallery

Odoo 18 后台表单：One2many 多图一站式体验—— 批量上传（拖入多张或一次多选文件）、 放大预览（点击缩略图全屏灯箱，Esc / 遮罩 / 关闭钮退出）、 下载（每张图左下角单张下载；顶部「Download all (ZIP)」打包已保存行）。 视图中使用 widget="drag_drop_images" 即可，子表需图片字段与可选 name 作为文件名/标题。

English: One2many image gallery with multi-file upload, click-to-zoom preview (lightbox), and per-image + ZIP batch download — configure via drag_drop_images and XML options.

核心能力 · Upload · Preview · Download

批量上传

将多张图片拖入虚线区域，或点击「Drag or Upload」在文件对话框中一次选择多个文件； 每张图会创建一行子记录。上传时自动把原始文件名写入子表 name（需在子模型中定义该字段），便于列表与下载命名。

放大预览

点击缩略图本身打开深色遮罩灯箱，大图按窗口自适应显示； 按 Esc、点击空白遮罩或右上角 × 关闭。可选 enable_zoom 开启悬停轻微放大动效。

下载

单张：左下角绿色圆形按钮，在当前页触发保存，不新开标签（同域 /web/image）。
批量：工具栏「Download all (ZIP)」仅打包已保存子行；未保存请先保存主表单。ZIP 内文件名优先用子行 name。

模块能做什么 · Overview

  • 挂件：drag_drop_images，用于 One2many 字段。
  • 批量上传：拖放多文件或文件选择器 multiple；创建多行子记录；子表 name 建议用于文件名展示（挂件已声明 name 可写，避免保存丢失）。
  • 放大预览：点击缩略图打开灯箱；键盘与遮罩关闭。
  • 下载：单张不跳新标签；批量 ZIP 走服务器路由（需已保存子行且有读权限）。
  • 子模型：需二进制/Image 字段（常用 image_1920）；可选派生缩略字段作 previewImage，避免 RPC 无效字段。
  • 主题兼容：删除、下载、ZIP 等控件优先使用 <span role="button">，降低主题隐藏小号 <button> 的影响。
  • 内置演示：菜单 mln Drag Drop → Demo，可立即试拖、预览、下载与 ZIP。

快速接入 · XML 示例

子模型含图片字段（示例 image_1920）与 name（推荐，用于标题与下载名）：

<field name="line_ids"
       widget="drag_drop_images"
       options="{
           'childImageField': 'image_1920',
           'acceptedFileExtensions': 'image/*',
           'extraData': {
               'previewImage': 'image_128',
               'cssStyles': 'width:120px;height:120px;object-fit:cover;border-radius:8px;',
               'enable_zoom': true
           }
       }"/>

options 摘要：
childImageField：子表存图字段，默认 image_1920。
acceptedFileExtensions：默认 image/*，支持批量选择符合类型的文件。
extraData：新建行默认值；其中 previewImage、cssStyles、enable_zoom / enableZoom 仅 UI，不写入库；其余键可作子表其它字段默认值。
灯箱预览、单张下载、ZIP 为挂件内置能力，无需额外 options 开关（ZIP 依赖子行已保存）。
完整说明见模块内 README.md。

常见问题 · FAQ

ZIP 按钮点了没反应？
批量 ZIP 只包含已保存的子行。请先保存主表单；若全是新建未落库行，会提示先保存。
缩略图下名字都是 “Image”？
请使用当前版本：子表 name 已在 relatedFields 中设为可写，上传时会写入原始文件名；旧数据需重传或手改 name。
保存前能看到图，保存后空白？
子表图片字段需可写 relatedFields；并检查子表是否有其它必填字段未在 extraData 中给默认值。
删除按钮不显示？
多为主题隐藏表单内小按钮；本模块删除用 span。请升级模块并强刷资源缓存。
从 eis_drag_drop 迁移？
卸载旧模块后安装 mln_drag_drop，详见 README.md。
