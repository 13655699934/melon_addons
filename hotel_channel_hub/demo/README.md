## 💡 使用场景

### 1. 测试房间查询
```bash
# 查看所有可售房间
在 Odoo 中：酒店管理 → 房间 → 筛选：状态=可售
```

### 2. 测试订单创建
```bash
# 创建新订单
在 Odoo 中：酒店管理 → 订单 → 创建
选择酒店 → 选择房型 → 输入客人信息 → 确认
```

### 3. 测试渠道对接
```bash
# 通过API创建订单
POST /api/order/create
{
  "hotel_id": 1,
  "room_type_id": 3,
  "channel_id": 1,
  ...
}
```

### 4. 测试数据看板
```bash
# 查看运营数据
在 Odoo 中：酒店管理 → 数据看板
- 查看入住率趋势
- 查看渠道销售对比
- 查看房间状态分布
```

## ⚠️ 注意事项

1. **数据冲突**: 
   - 演示数据使用 `noupdate="1"`，重复安装不会覆盖已修改的数据
   - 如需重置，请先删除相关记录再重新安装模块

2. **日期动态**:
   - 订单的入住/离店日期使用相对时间 (`DateTime.now() + timedelta(days=N)`)
   - 确保系统时间正确，避免日期异常

3. **依赖关系**:
   - 订单依赖房间、房型、酒店、渠道数据
   - 删除时需注意级联关系

4. **字段映射**:
   - 确保模型字段名与demo数据中的字段名一致
   - 如修改过模型结构，可能需要同步更新demo数据
