🏨 酒店管理与渠道聚合系统

版本: 18.0.1.0.0 | 作者: melon | 许可证: LGPL-3

📋 系统概述

这是一套完整的酒店管理与渠道聚合解决方案，专为 Odoo 18 社区版 设计开发。 系统支持酒店、房型、房间的全面管理，提供线上线下订单处理，集成多渠道API接口， 实现酒店与第三方OTA平台的无缝对接。

✨ 核心功能

🏢 酒店基础管理

  • 多酒店、多公司支持
  • 酒店信息管理（地址、联系方式、星级）
  • 房型定义（床型、价格、设施、取消规则）
  • 房间管理（房态、价格、售卖类型）
  • 实时房态更新（空闲、预订、入住、维修）

📝 订单全流程管理

  • 线上线下订单统一管理
  • 订单流程：草稿 → 确认 → 入住 → 退房
  • 支持订单取消与退款
  • 一键复刻功能：快速复制订单重新下单
  • 订单日历与看板视图
  • 订单确认单打印（含二维码）

🌐 渠道聚合与API

  • 多渠道接入（携程、美团、飞猪等）
  • 企业唯一标识 + Token 认证机制
  • Token自动生成与轮换
  • RESTful JSON API接口
  • 渠道映射与定价策略（加价、减价、固定价）
  • 接口调用日志与审计

📊 库存与价格管理

  • 按日期管理房间库存
  • 总库存、已售、可售自动计算
  • 批量更新价格与库存
  • 库存预警机制
  • 开放售卖状态控制

📈 数据看板与报表

  • 实时在住统计
  • 近7天/30天订单与收入分析
  • 按酒店/渠道/房型的多维度统计
  • 订单图表与透视表
  • 消息面板与告警通知

🔐 权限与安全

  • 四级权限：酒店经理、渠道经理、前台用户、API客户端
  • 多公司数据隔离
  • 记录级权限控制
  • 价格修改权限保护
  • 操作日志与审计追踪

🔌 API接口说明

接口格式: JSON-RPC | 认证方式: Enterprise Key + Token

接口列表

  1. POST /api/channel/token - 获取企业接入Token
  2. POST /api/hotel/rooms - 获取酒店房间列表（支持分页）
  3. POST /api/order/create - 创建订单
  4. POST /api/room/update - 批量更新房间价格与库存
  5. POST /api/order/update - 更新订单（取消、改期）
  6. POST /api/order/detail - 查询订单详情

响应格式

{
    "code": 0,           // 0=成功, -1=失败
    "msg": "成功",
    "data": {...},
    "timestamp": 1699430400
}

🚀 安装与部署

环境要求

  • Odoo 18 Community Edition
  • Python 3.11+
  • PostgreSQL 14+

安装步骤

  1. 将模块复制到 Odoo addons 目录
  2. 更新应用列表
  3. 搜索"酒店管理"并安装
  4. 安装完成后进入"酒店管理"菜单开始使用

演示数据

安装模块时会自动创建演示数据，包括：

  • 2家酒店（天悦大酒店、云端商务酒店）
  • 3种房型（豪华大床房、行政双床房、标准大床房）
  • 5个房间
  • 2个渠道（携程、美团）
  • 5个订单样例

📖 使用指南

快速开始

  1. 创建酒店：酒店管理 → 酒店信息 → 酒店
  2. 定义房型：酒店管理 → 酒店信息 → 房型
  3. 添加房间：酒店管理 → 酒店信息 → 房间
  4. 设置渠道：酒店管理 → 渠道管理 → 渠道
  5. 创建订单：酒店管理 → 订单管理 → 订单

API接入

  1. 在系统中创建渠道记录，获取 enterprise_key
  2. 调用 /api/channel/token 获取Token
  3. 使用Token调用其他API接口
  4. 查看"同步日志"监控接口调用情况
