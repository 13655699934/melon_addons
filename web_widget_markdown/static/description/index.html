Web Widget Text Markdown

为 Odoo 表单字段添加 Markdown Widget支持

主要功能

✨ 实时预览
支持 Markdown 实时编辑和预览切换，让您的文档编辑更加直观。
📝 完整语法支持
支持标题、列表、链接、代码块等常用 Markdown 语法。
🎨 美观的渲染效果
使用现代化的样式渲染 Markdown 内容，提供良好的阅读体验。

应用模块

预览模式

使用方法

1. 在字段定义中使用
在 Python 模型中定义字段时，设置 widget 属性为 "bootstrap_markdown"： 
 description = fields.Text(string="描述")
2. 在视图中使用
在表单视图中使用 widget 属性： 
<field name="description" widget="bootstrap_markdown"/>
