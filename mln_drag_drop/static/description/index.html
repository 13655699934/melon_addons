mln · Drag Drop Image Gallery

Odoo 18 backend forms: One2many multi-image in one place — batch upload (drag in several images or multi-select in the file dialog), zoom preview (click a thumbnail for a full-screen lightbox; close with Esc, backdrop, or the close control), download (per-image button bottom-left; toolbar Download all (ZIP) for saved lines only). Use widget="drag_drop_images" in the view; the child model needs an image field and optional name for file name / title.

Core features · Upload · Preview · Download

Batch upload

Drag multiple images into the dashed area, or click Drag or Upload and multi-select in the file dialog; each image creates one child line. On upload, the original file name is written to child name (define that field on the child model) for list display and download names.

Zoom preview

Click the thumbnail to open a dark overlay lightbox; the large image scales to the window. Close with Esc, clicking the backdrop, or the × control. Optional enable_zoom adds a slight hover zoom effect.

Download

Single: green circular button bottom-left; triggers save on the current page, same tab (same-origin /web/image).
Bulk: toolbar Download all (ZIP) only packs saved child lines; save the parent form first. ZIP entry names prefer child line name.

Overview

  • Widget: drag_drop_images for One2many fields.
  • Batch upload: multi-file drag-and-drop or file input multiple; creates one child row per image; child name recommended for captions (widget marks name writable so values are not lost on save).
  • Zoom preview: click thumbnail for lightbox; Esc and backdrop to close.
  • Download: single image without a new tab; bulk ZIP via server route (requires saved child rows and read access).
  • Child model: needs a binary / image field (often image_1920); optional derived thumbnail as previewImage to avoid invalid RPC fields.
  • Theme compatibility: delete, download, and ZIP controls prefer <span role="button"> to reduce themes hiding small <button> elements.
  • Built-in demo: menu mln Drag Drop → Demo to try drag, preview, download, and ZIP immediately.

Use cases

  • Multi-image entry with on-screen zoom to check details
  • Handing images to customers or warehouse (single or ZIP)
  • Mostly XML/UI changes with minimal Python business logic

Quick start · XML example

Child model with an image field (example image_1920) and name (recommended for title and download name):

<field name="line_ids"
       widget="drag_drop_images"
       options="{
           'childImageField': 'image_1920',
           'acceptedFileExtensions': 'image/*',
           'extraData': {
               'previewImage': 'image_128',
               'cssStyles': 'width:120px;height:120px;object-fit:cover;border-radius:8px;',
               'enable_zoom': true
           }
       }"/>

Options summary:
childImageField: child field that stores the image; default image_1920.
acceptedFileExtensions: default image/*; batch selection accepts matching types.
extraData: defaults for new lines; previewImage, cssStyles, enable_zoom / enableZoom are UI-only; other keys become defaults for other child fields.
Lightbox, single download, and ZIP are built into the widget — no extra option switches (ZIP still requires saved child rows).
Full details: README.md in the module.

FAQ

ZIP button does nothing?
Bulk ZIP only includes saved child lines. Save the parent form first; if all lines are new and unsaved, you will be prompted to save.
Captions under thumbnails all say “Image”?
Use the current version: child name is writable in relatedFields and receives the original file name on upload; fix old rows by re-uploading or editing name.
Images visible before save, blank after?
Ensure the child image field is writable in relatedFields; check required child fields not covered by extraData defaults.
Delete control not visible?
Often the theme hides small form buttons; this module uses a span for delete. Upgrade the module and hard-refresh assets.
Migrating from eis_drag_drop?
Uninstall the old module, then install mln_drag_drop; see README.md.
